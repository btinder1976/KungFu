# Touchstone Martial Arts Website Starter

Modern static website starter for Touchstone Martial Arts / Sacramento Kung Fu.

## What is included

- `index.html` — one-page modern landing site
- `styles.css` — Kung Fu themed visual design
- `script.js` — mobile menu and footer year
- `robots.txt` — search crawler and AI crawler hints
- `sitemap.xml` — basic sitemap
- `llms.txt` — AI-search summary file

## SEO included

- Title and meta description
- Local Sacramento + Wing Chun keyword targeting
- Open Graph social tags
- LocalBusiness / SportsActivityLocation JSON-LD schema
- FAQ schema
- AI-focused `llms.txt`

## Deployment options

### GitHub Pages
Use repository settings → Pages → deploy from main branch root.

### Netlify
Drag and drop the folder, or connect the GitHub repository.

### Cloudflare Pages
Connect the GitHub repository and set build output to `/` with no build command.

## Notes

This starter intentionally does not process payments. It is designed as a strong public-facing brochure and inquiry site that can later grow into scheduling, class booking, student login, or curriculum pages.
